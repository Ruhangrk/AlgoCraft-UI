# AlgoCraft-UI

React frontend for the AlgoCraft C++ trading engine.

## Stack

Vite · React 19 · TypeScript · Tailwind CSS 4 · React Router · TanStack Query

## Setup

```bash
cp .env.example .env
npm install --maxsockets=3
npm run dev
```

App: `http://127.0.0.1:5173`  
API (default): `http://127.0.0.1:8080` via `VITE_API_URL`
